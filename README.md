## Projects

### [Lalai](https://lalai.io)

Lalai is an enterprise AI orchestration platform designed to help organizations create, deploy, and manage intelligent agents within their existing business workflows. Built with Laravel, Vue, Inertia.js, and Tailwind CSS, the platform provides a secure application layer between users, organizational data, communication channels, and multiple AI model providers.

The platform integrates with Microsoft 365 services, including Microsoft Teams and Outlook, so AI agents can participate in familiar workplace experiences. Its provider-independent architecture allows AI workloads to be routed through different model providers without coupling the application's core business logic to a single vendor.

Lalai's Model Gateway serves as the control boundary for AI operations. It coordinates authorization, provider routing, retries, idempotency, usage metering, cost tracking, customer data boundaries, and sanitized audit records. Provider credentials and configuration are resolved at invocation time to reduce the risk of exposing secrets or mixing customer data between requests.

A central focus of Lalai is organizational learning. Its knowledge architecture is designed to preserve useful experiences as structured, reusable knowledge, enabling agents to maintain continuity across conversations and workflows. The system emphasizes canonical entities, stable identifiers, aliases, relationships, source attribution, and contextual retrieval rather than relying only on unstructured conversation history.

The project also includes a public research and learning component covering topics such as AI employment, agent memory, learning architecture, and enterprise AI adoption.
